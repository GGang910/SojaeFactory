# 소재공장 (Sojae Factory)

SillyTavern에서 롤플레이 **소재·전개 방향을 추천받고, 보관하고, 메모하는** 확장입니다.
모바일 화면에 맞춰 만들었어요.

## 설치

SillyTavern → 확장(🧩) → **Install Extension** → 아래 주소 입력

```
https://github.com/GGang910/SojaeFactory
```

설치 후 🪄 마법봉 메뉴의 **소재공장**, 또는 채팅창에 `/소재` (`/sojae`)로 엽니다.

## 기능

### 🎲 추천
- **전개 방향** 모드: 관계를 한 걸음씩 움직일 사건·계기·갈등·복선을 추천
- **일상 소재** 모드: 지금 관계에서 즐길 수 있는 소소한 일상 에피소드를 추천
- 조건: 장르·배경, 분위기, 관계 방향, 전개 속도, 계절·이벤트, 추가 요청
- **등장인물 (다인봇 전용)**: 인물 이름을 적으면 그 인물의 소재만 추천
- 카드마다 **보관 / 복사 / 리롤**(그 카드만 다시 뽑기)
- 최근 결과 최대 20개 보관, 최신순 정렬, 번호 표시

### ⭐ 보관함
- 전체 공용 / 봇별 보관함

### 📝 메모
- 전체 / 봇별 개인 메모장 (AI에게 보내지 않음)

### ⚙️ 설정
- **추천에 쓸 API**: 현재 연결 또는 ST 연결 프로필(Connection Profile) 중 선택 — 채팅 연결은 그대로
- **월드인포**: 봇별로 로어북을 고르고 보낼 항목만 체크 (토큰 수는 ST 월드인포 창과 동일), 켜기/끄기
- 소재 언어 (한국어 / English / 日本語 / 中文), 추천 개수, 참고 대화 턴 수, 중복 방지 개수, 최대 토큰

## 보내는 내용

추천 요청에는 이 확장이 만든 프롬프트만 들어갑니다.
캐릭터 설정, 골라둔 월드인포 항목, 최근 대화(설정한 턴 수), 최근 추천 결과(중복 방지용), 고른 조건.

- 프리셋의 프롬프트 토글·탈옥문은 들어가지 않습니다.
- 다른 확장이 프롬프트에 끼워 넣는 내용(전개지시, 프리필 등)은 소재공장 요청에서만 걷어냅니다. 메인 채팅에는 영향 없음.

## 데이터 저장 위치

- 보관함·메모·봇별 설정: SillyTavern `settings.json`의 `extension_settings.sojae_factory`
- 추천 결과: 각 채팅 파일의 메타데이터
- 캐릭터 카드와 로어북 파일은 수정하지 않습니다.
