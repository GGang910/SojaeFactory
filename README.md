# 소재공장 (Sojae Factory)

SillyTavern에서 롤플레이 **서사 로드맵과 소재를 추천받고, 보관하고, 메모하는** 확장입니다.
모바일 화면에 맞춰 만들었어요.

## 설치

SillyTavern → 확장(🧩) → **Install Extension** → 아래 주소 입력

```
https://github.com/GGang910/SojaeFactory
```

설치 후 🪄 마법봉 메뉴의 **소재공장**, 또는 채팅창에 `/소재` (`/sojae`)로 엽니다.

## 기능

### 🎲 추천
- **서사 로드맵** 모드: 지금 관계(예: 처음 보는 사이)에서 **목표 관계**(예: 연인)까지 3~7단계로 차근차근 밟아갈 서사를 설계
  - 단계마다 핵심 사건과 **끝나면 관계가 어디까지 오는지(도달)** 표시
  - 이전 단계가 쌓여야 다음이 성립하도록 순서·인과를 맞춤, 1단계는 다음 채팅에서 바로 시작 가능
  - 마음에 안 드는 단계는 **[다시 짜기]**로 그 단계만 앞뒤에 맞게 교체, **전체 복사** 지원
- **일상 소재** 모드: 지금 관계에서 즐길 수 있는 소소한 일상 에피소드를 추천 (최근 20개 보관, 카드별 리롤)
- 조건: 장르·배경, 분위기, 목표 관계·단계 수(로드맵), 일상 테마·계절·이벤트(일상), 추가 요청
- **등장인물 (다인봇 전용)**: 인물 이름을 적으면 그 인물의 이야기만 추천
- 카드마다 **보관 / 복사** (복사하면 소재 문장만 복사돼서 전개지시 칸에 바로 사용)

### ⭐ 보관함
- 전체 공용 / 봇별 보관함
- 추천 카드의 ★ 보관은 보관함 탭에서 **선택된 쪽**으로 저장 (봇 채팅 중엔 기본이 그 봇)
- 카드의 [봇으로] / [전체로] 버튼으로 옮기기

### 📝 메모
- 전체 / 봇별 개인 메모장 (AI에게 보내지 않음, 봇 채팅 중엔 기본이 그 봇)

### ⚙️ 설정
- **추천에 쓸 API**: 현재 연결 또는 ST 연결 프로필(Connection Profile) 중 선택 — 채팅 연결은 그대로
- **월드인포**: 봇별로 로어북을 고르고 보낼 항목만 체크 (토큰 수는 ST 월드인포 창과 동일), 켜기/끄기
- 소재 언어 (한국어 / English / 日本語 / 中文), 추천 개수, 참고 대화 턴 수, 중복 방지 개수, 최대 토큰
- 패널 불투명도 (70~100%)

## 보내는 내용

추천 요청에는 이 확장이 만든 프롬프트만 들어갑니다.
캐릭터 설정, 골라둔 월드인포 항목, 최근 대화(설정한 턴 수), 최근 추천 결과(중복 방지용), 고른 조건.

- 프리셋의 프롬프트 토글·탈옥문은 들어가지 않습니다.
- 다른 확장이 프롬프트에 끼워 넣는 내용(전개지시, 프리필 등)은 소재공장 요청에서만 걷어냅니다. 메인 채팅에는 영향 없음.

## 데이터 저장 위치

- 보관함·메모·봇별 설정: SillyTavern `settings.json`의 `extension_settings.sojae_factory`
- 추천 결과: 각 채팅 파일의 메타데이터
- 캐릭터 카드와 로어북 파일은 수정하지 않습니다.

## 변경 기록

### 1.2.0
- **"전개 방향"을 "서사 로드맵"으로 교체**: 여러 후보를 나열하던 방식 대신, 현재 관계에서 목표 관계까지 단계별로 이어지는 서사를 설계
- 조건 "관계 방향 / 전개 속도" → **"목표 관계 / 단계 수(3~7)"**
- 단계별 **도달 상태** 표시, 단계 하나만 앞뒤에 맞게 **다시 짜기**, 로드맵 **전체 복사**

### 1.1.0
- 보관함·메모가 봇 채팅 중엔 기본으로 **그 봇**에 선택되도록 변경 (전체에 잘못 저장되는 문제)
- 보관함 카드에 [봇으로] / [전체로] 옮기기 버튼
- 설정에 **패널 불투명도** 추가 (기본 90%)
- 설정의 슬라이더를 [ − ] 숫자 [ + ] 로 변경 — 모바일에서 스크롤하다 값이 바뀌던 문제 수정
- 모바일에서 글 입력 중 추천받기 버튼이 키보드 위로 올라와 가리던 문제 수정
